# Differential persistence from finite local resource flow

## Status and scope

This is a testable toy hypothesis, not a claim of novelty, universal biology, or demonstrated intelligence. The proposed common law is **differential persistence under a finite local resource flow**. Cell abundance, connection persistence, cell death, and fission change through resource mass. There is no separate survival score, age clock, population cap, or hand-set fitness threshold.

The preceding `ecology.py` model is retired as evidence for this principle. Its energy cutoffs, scheduled division, population cap, unused error state, and periodic niches made its ecological interpretation depend too heavily on hand-coded rules. Its results remain in `sim/ecology_results.json` as historical output and are not used below.

## Formal model

At sensory time `t`, the environment supplies `K=3` independent fair binary source channels `x_0,x_1,x_2`. A target channel is generated by

```text
y_t = x_{s*(t),t} XOR xi_t,       xi_t ~ Bernoulli(0.08)
```

The active source `s*(t)` follows the hidden schedule `0,1,2,0`, with each phase lasting 600 samples. The target is a sensory observation, not a reward or label. Cells receive all source channels and the target after predicting it; the phase and active-source identity are hidden.

The population `P_t` is a finite multiset of cells. Cell `i` has source-edge identity `s_i in {0,1,2}`, resource mass `m_i >= 0`, and two local Beta-Bernoulli count pairs `(a[i,b], n[i,b])`, for `b in {0,1}`. Its prediction for target value 1 is

```text
q_i(x[s_i]) = (a[i,x[s_i]] + 1) / (n[i,x[s_i]] + 2)
```

The observation update increments `n[i,x[s_i]]` by 1 and `a[i,x[s_i]]` by `y_t`. This local count update does not use backpropagation. Fast prediction error is `e_i(t) = (q_i - y_t)^2`, measured before the count update.

Each sample, a shared finite resource inflow `Q_t ~ Poisson(S)` arrives as unit packets. Packets are apportioned uniformly among extant cells. Cell `i`'s signed mass change is

```text
J_i(t) = I_i(t) - c - lambda * e_i(t)
```

where `I_i(t)` is its packet intake, maintenance `c=0.10`, and prediction-error dissipation coefficient `lambda=0.25`. The mass update is `m_i <- m_i + J_i(t)`. If mass is depleted to zero, the cell dies and its source edge disappears. If accumulated mass reaches two normalized cell-mass units, it splits into two equal-mass daughters. Fission conserves mass. Doubling is the physical fission rule for this model, not a fitted viability or performance threshold; there is no scheduled division time.

At fission, the daughter inherits the source edge and predictor counts. With probability `mu`, it instead mutates its source uniformly to one of the other channels and resets its predictor to the symmetric Beta prior. Thus edge variants are created only in resource-funded daughters; their persistence or pruning follows the same mass balance as every other cell.

The only varied causal law is how prediction-dependent dissipation is assigned:

- **Selected:** each cell pays `lambda * e_i(t)`, so a locally useful edge changes its carrier's mass trajectory.
- **Neutral random-mutation control:** each cell pays `lambda * mean_i(e_i(t))`. Total prediction-dependent resource use matches the selected condition at that sample, but no edge receives cell-specific advantage. Mutations still occur randomly at birth.
- **Mutation-supply control:** the same neutral allocation with `mu=0.15` instead of `0.05`, testing whether greater random-variant supply alone explains tracking. This rate was chosen in a follow-up to exceed the selected run's observed mutation count; it is a sensitivity control, not an independently preregistered parameter.

There is no imposed maximum population. The experiment has three possible source-edge types by construction, while the number of cells and active edge instances can grow and shrink freely.

## Hypothesis and falsifier

**H1 — predictive usefulness changes structure through differential persistence.** When local prediction loss enters the same resource balance that drives mass, fission, and depletion, the population should shift toward the currently predictive source after a hidden regime change. It should outperform neutral populations with the same total prediction-related resource expenditure and random mutation, including a control with equal-or-greater mutation supply.

The hypothesis would be refuted if, over paired seeds, the resource-selected condition did not increase current-source edge share and lower target MSE relative to both neutral controls, or if its advantage disappeared when substrate supply changed moderately. It would also fail as an architectural rule if it relied on explicit survival, proliferation, or population-cap cutoffs to produce the effect.

## Interpretation and limits

This experiment supports H1 inside the stated toy model: resource allocation linked to fast prediction error reorganized which source edges persisted, and the effect was not explained by the tested random-mutation supply. Slow cell mass integrates the fast error-dependent flow; predictor counts persist by inheritance while their carrier remains viable. Growth and pruning are opposite outcomes of the same mass trajectory.

This is not evidence that neural prediction error biologically controls cell proliferation. The biolog agent's report on Turrigiano (2012) supports separating fast activity from slower homeostatic state in synaptic scaling, but does not support a prediction-error-to-proliferation link. The mass-flow mechanism is an abstraction to test, not a biological fact. This experiment has only three candidate edges, a fixed environment family, and a simple local predictor; it does not demonstrate action, gridworld learning, Crafter performance, or general intelligence. Next: independent reproduction through the shared stream benchmark and stress tests with longer regime sequences, resource heterogeneity, and extinction/recovery.

## Audit boundary of H003

The critic's audit is correct: H003 is an instance of differential reproduction/selection, a known family, and its first implementation does not derive all organismal behavior from mass flow. Beta-Bernoulli counts update independently of mass, and a fixed mutation probability and distribution propose new edges. The three source types are all present at initialization. H003 therefore supports only this narrow causal statement: cell-specific predictive cost changes differential persistence under the chosen finite-resource stream. The equation does not establish a complete one-principle account of learning, memory, and exploration.

The independent shared stage-1 stream adapter is a material negative result for transfer. In its five 6000-step runs, `ResourceFlowPredictor` reached target MSE `0.1876`, slower mean adaptation (`345.7` steps), and mean return MSE `0.1800`; `fixed_hebb` and `growing` had target MSE `0.1124` and `0.1053`. The adapter ended with 64 connections and 80 units after about 20,393 growth and pruning events each. As the critic notes, this is diagnostic rather than a registered falsification of H003: it has no neutral resource-flow arm and no active-edge-share metric, and it retained both the Beta estimator and fixed mutation rate. The poor transfer result prevents treating the toy result as a good general stream learner.

## H004 candidate: ecological learning with fission-linked exploration

This variant removes the within-cell predictor and the independent mutation-rate parameter. A cell is `(s_i, m_i)`, where `s_i` is one source edge and `m_i` is resource mass. Its prediction is the raw sensory bit `x[s_i]`; the instantaneous error is `e_i(t) = 1[x[s_i] != y]`. Each time step, a finite Poisson number of substrate packets is apportioned uniformly among extant cells. The single signed flow is

```text
J_i(t) = I_i(t) - c - lambda * e_i(t)
m_i(t+1) = m_i(t) + J_i(t)
```

If `m_i(t+1) <= 0`, the process and its edge disappear. If mass reaches two normalized units, it splits into equal masses. One daughter retains the source edge; the other samples uniformly from the other available sources. This daughter-edge sampling is coupled to fission and has no separate mutation probability or clock. A neutral control substitutes the population mean error for `e_i`, preserving total error-dependent expenditure at each sample while removing edge-specific resource advantage. A clonal control makes both daughters retain the parental edge.

There is no individual parameter update in this model. **Learning** means a change in the population frequency of source edges under differential persistence; **memory** is the surviving edge composition; **pruning** is loss of edge-bearing processes at depletion; **growth** is resource-funded fission; and **exploration** is the fission-linked daughter variant. The last item is not yet derived from the mass equation alone: the uniform alternative-source sampling rule remains an explicit structural assumption. Thus H004 tests a stronger ecological account than H003, but does not close the single-principle problem.

The falsifiable prediction is that in a reward-free stream with three possible sources, starting with source 2 absent, cell-specific error cost plus fission-linked variation will increase source-2 abundance after a hidden switch to source 2, outperform a neutral-resource control with identical fission variation, and retain the advantage when total substrate supply changes by `±10%`. It should also re-express source 0 after the final return to that regime. H004 is refuted if the selected population fails to discover and increase the missing edge, fails to outperform the neutral arm on active-edge share and target MSE, or loses the effect under the tested supply perturbation. The clonal arm checks that a missing edge cannot appear without variation.

The executed test used source schedule `0→1→2→0` with four 800-sample phases, three binary input sources, target noise `0.08`, initial population 45 split across sources 0 and 1, and 30 paired seeds. Neither model condition received the active-source label or reward. The selected arm used `c=0.10`, `lambda=0.25`, and mean substrate inflow `7.7625`; fission was the only source of births and edge changes. Measurement averaged samples 100–300 after each of the three regime changes.

| Condition | Post-shift active-edge share | Target MSE | Source-2 share after its first appearance | Extinctions |
|---|---:|---:|---:|---:|
| Selected resource flow, fission variation | 0.4702 | 0.3049 | 0.4716 | 0/30 |
| Neutral flow, same fission variation | 0.3355 | 0.3635 | 0.3357 | 0/30 |
| Selected flow, clonal fission | 0.3333 | 0.3524 | 0.0000 | 0/30 |

All 30 paired seeds favored selected fission variation over the neutral arm on both matching-source share and target MSE. The paired share difference was `+0.1347` (95% paired t interval `[0.1295, 0.1398]`); the paired MSE difference was `-0.0586` (`[-0.0632, -0.0539]`). Every varied-arm birth made exactly one sampled daughter; the clonal arm made none. This confirms that the absent source can enter through fission and then gain abundance through resource selection. It does not show that selection alone generates variants.

At `0.9×` and `1.1×` substrate supply, selected active-edge share / MSE were `0.4766/0.3024` and `0.4682/0.3080`; neutral values were `0.3346/0.3596` and `0.3350/0.3608`. There were no extinctions. On this harder discovery test, adaptation is substantially weaker than H003's three-source-initialized Beta-predictor test. The gain from removing separate learner counts and a mutation-rate constant is a cleaner ecological interpretation; the cost is slower, less accurate prediction.

Implementation: [sim/resource_flux_ancestry.py](sim/resource_flux_ancestry.py). Full seed traces and supply perturbations: [sim/resource_flux_ancestry_results.json](sim/resource_flux_ancestry_results.json). The code ran on CPU with `.venv` and `nice -n 15`.

## H005 candidate: typed resource flow materializes edges

H005 removes H004's explicit daughter-edge sampling rule. Substrate is now a finite set of unit packets `(mass=1, label=k)`, where `k` is a candidate source-edge identity drawn uniformly over the sensory input channels. Packets are assigned uniformly among extant cells. The label is a structural payload in the resource flow, not a reward, regime label, or mutation event. Each cell still carries only `(s_i,m_i)` and predicts the raw bit `x[s_i]`.

For each sample, each cell's prediction error is `e_i=1[x[s_i] != y]`. It receives `I_i` unit packets and records the label `k_i^last` of the latest packet delivered to it that sample. The sole signed mass law is

```text
J_i = I_i - c - lambda*e_i
m_i' = m_i + J_i
```

At `m_i' <= 0`, the process dies and its connection disappears. At `m_i' >= 2`, its mass is divided equally. The parental daughter retains `s_i`; the other daughter takes `k_i^last`, the structural label of the latest resource entering at that fission. No mutation probability, mutation clock, separate edge-sampling kernel, within-cell estimator, age gate, or population cap is used. In the neutral control, all cells pay the same population-mean error cost, while packet count, packet labels, and fission-linked edge assignment are unchanged. The clonal control ignores packet labels at fission.

The irreducible assumption is now explicit: resource is typed by a candidate edge identity, with uniform packet labels. The model does not derive why a physical substrate should carry an edge label. It does, however, make structural variation an incoming-material effect rather than an independent mutation operator. As in H004, population abundance is the learned state, and persistent edge composition is ecological memory.

The falsifiable prediction is that selected cell-specific flow will discover source 2, absent from the initial population, raise its abundance after the hidden switch to source 2, and outperform neutral tagged-resource flow on active-edge share and target MSE. This should remain true at `±10%` substrate supply. H005 is refuted if the absent source fails to enter and increase, if selected and neutral populations do not differ in both active-edge share and MSE across paired seeds, or if the effect disappears under the tested supply changes.

The implementation is [sim/resource_flux_tagged_fission.py](sim/resource_flux_tagged_fission.py); complete runs are in [sim/resource_flux_tagged_fission_results.json](sim/resource_flux_tagged_fission_results.json). This CPU simulation ran with `.venv` and `nice -n 15`. It used the same 30-seed, 3200-step, `0→1→2→0` regime test and initial edge set `{0,1}` as H004. The environment revealed neither regime identity nor reward. Mean post-shift results were:

| Condition | Active-edge share | Target MSE | Source-2 share after its first appearance | Variant daughters per birth | Extinctions |
|---|---:|---:|---:|---:|---:|
| Selected tagged-resource flow | 0.5989 | 0.2531 | 0.5953 | 0.6644 | 0/30 |
| Neutral tagged-resource flow | 0.3335 | 0.3609 | 0.3304 | 0.6628 | 0/30 |
| Selected clonal fission | 0.3333 | 0.3485 | 0.0000 | 0.0000 | 0/30 |

All 30 paired seeds favored selected over neutral flow for both metrics. The active-share difference was `+0.2654` (95% paired t interval `[0.2564,0.2743]`), and the MSE difference was `-0.1078` (`[-0.1182,-0.0973]`). Packet labels were empirically close to uniform in all conditions, and the selected and neutral arms produced nearly identical variant-daughter fractions per birth. The clonal arm never produced source 2. Thus the observed advantage cannot be attributed to a more frequent edge label per birth; it requires cell-specific resource consequences.

The tag-coded flow improved over H004's explicit alternative-edge fission sampler on every paired seed: active-edge share improved by `0.1287` (`[0.1209,0.1365]`) and MSE decreased by `0.0518` (`[-0.0598,-0.0438]`). At `0.9×` and `1.1×` resource supply, selected share / MSE were `0.6024/0.2499` and `0.6037/0.2464`; neutral values were `0.3351/0.3606` and `0.3356/0.3552`. No run went extinct. After source 0 returned, the selected population restored source 0 to mean share `0.5749`, versus `0.3285` in neutral flow. These are simulation outcomes, not biological measurements.

## Remaining derivation problem

Typed resource flow removes an independent mutation operator, but it places a candidate-edge label in the substrate by assumption. Next test whether the same results survive a principled, nonuniform or dynamically expanding structural label space, and whether packet tags can be generated by local sensory contact without target/regime access. The model still has only three source-edge phenotypes and uses population composition rather than an internal adaptive predictor. Neither H004 nor H005 establishes that prediction-error dissipation causes biological proliferation; the biologist has not identified such a direct mechanism in the sources reviewed.
